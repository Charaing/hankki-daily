# 한끼 구현 계획

software · 한국어 식단 기록 앱. 토스에서 영감을 받은 밝은 배경, 선명한 파랑, 큰 숫자, 넉넉한 여백과 짧은 문장. 사용자의 바로 진행 요청에 따라 플랫폼과 세부 기능은 구현자가 결정한다.

정적 HTML/CSS/JavaScript와 GitHub Pages로 로그인 없이 접속한다. 기록은 브라우저 로컬 저장소에 보관하며 JSON 백업·복원을 제공한다. 서버 동기화는 제공하지 않는다. 공개 저장소에는 사용자의 식단을 넣지 않는다.

- [ ] 데이터: 식약처 음식·가공식품 최신 공개 파일을 100g/100mL 기준으로 변환한다. 출처·버전·제외 기준을 기록하고 원재료성 데이터도 확보한다. 식품 데이터는 Web Worker에서 점진적으로 검색한다.
- [ ] 계산: g/mL와 인분 기준의 소수 입력, 누락 영양소, 잘못된 수량과 복원 데이터 검증을 Node 테스트로 확인한다.
- [ ] 화면: 오늘 기록, 날짜 이동, 아침·점심·저녁·간식, 음식 검색, 즐겨찾기, 직접 등록, 양 편집, 삭제 취소, 칼로리·탄단지, 물, 주간 통계와 목표 설정을 구현한다.
- [ ] 검증: 1440·1024·768·390·320px 레이아웃, 키보드·모달, 실제 기록 저장·수정·삭제·복원, 배포 후 데이터 로딩을 확인한다.
- [ ] 게시: 새 공개 GitHub 저장소에 코드와 출처를 게시하고 GitHub Pages를 활성화해 실제 접속 URL을 확인한다.

판단 기준: 없는 영양소는 0으로 단정하지 않는다. mL를 g으로 임의 환산하지 않는다. 포장 중량은 1개/1팩 기준이라는 안내를 표시하며 인분 무게를 사용자가 수정할 수 있다. 기본 2,000kcal는 수정 가능한 예시 목표다. 검색 실패·저장 실패는 화면에 알린다. 입력 문자는 HTML로 해석하지 않는다.
