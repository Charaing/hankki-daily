# 1.4.0 검증

2026-11-15, 한끼

- 34개 Node 테스트 통과: 1인분 환산과 소수 인분, 무게 미상과 mL, 직접 등록 그룹 삭제·즐겨찾기 정리·되돌리기·기존 식단 보존, BMR 자동 비교 기준과 과거 목표 유지, 백업 복원 즉시 연동, 확대 입력 제어를 포함합니다.
- 실제 localhost 브라우저에서 210g/336kcal 음식을 1인분 기준으로 등록하고 0.5인분을 105g/168kcal로 저장했습니다. 등록 음식 삭제 후 식단은 유지되었고 되돌리기로 보관함에 복구했습니다.
- 1인분 무게가 없는 기존 음식은 입력 대기로 표시했습니다. g 모드로 전환한 뒤 인분 모드로 돌아와 50g을 입력하면 1인분 영양정보가 계산되는 것을 확인했습니다.
- 성인 테스트 프로필(170cm, 30세, 남성, 70kg)에서 추정값 1,618kcal가 오늘의 비교 기준에 즉시 반영되었습니다. 이 프로필은 localhost 검증용이며 공개 사이트에 입력하지 않았습니다.
- 달력의 날짜별 열량·차이 숫자와 선택 날짜의 열량 숫자를 제거했습니다. 목표 초과는 빨강, 목표 대비 적자는 파랑으로 확인했습니다.
- 390×844 모바일과 기본 데스크톱 화면에서 확인했습니다. 모바일 수평 넘침이 없고 Ctrl+= 입력 전후 화면 배율이 1로 유지되었습니다. 핀치·제스처 이벤트는 단위 테스트로 검증했으며 실제 iOS/Android 장치 검증은 하지 않았습니다. OS 또는 브라우저 메뉴 확대는 앱에서 차단할 수 없습니다.
- 독립 코드 검토에서 발견한 백업 복원 시 목표가 다음 실행까지 갱신되지 않는 문제를 수정하고 회귀 테스트를 추가했습니다.

칼로리 색은 설정한 비교 기준 대비 기록 합계입니다. BMR을 하루 권장 섭취량이나 실제 에너지 적자로 표시하지 않습니다. 신체 정보가 없으면 입력 전 임시 기준을 명확히 표시합니다. 학교 점심의 사용자 제공 추정 영양소·공휴일·제외 설정은 유지했습니다.
