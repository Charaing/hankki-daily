# 몸 관리와 모션 확장

사용자의 바로 진행 요청에 따라 기존 정적 앱에 통합한다. 디자인·계산·검증 스킬을 적용하며 별도 계정이나 서버는 추가하지 않는다. 기존 식단 데이터를 유지하고 새 항목을 백업에 포함한다.

- [ ] health-core.js: 한국 성인 BMI, Mifflin–St Jeor 휴식대사량 추정, 활동계수 기반 하루 소비열량, 유지/10% 감량/10% 증량 예시 목표, 체중 추이·날짜 범위·목표 진행, 신체·생활 기록 검증을 테스트부터 구현.
- [ ] core.js: 기존 version 1 백업과 저장소에 health 필드가 없으면 빈 상태를 채운다. 있으면 엄격히 검증한다. 기존 데이터는 제거하지 않는다.
- [ ] health-ui.js / health.css: 몸 관리 탭, 날짜별 체중·체지방·허리둘레, 7/30/90일/전체 그래프와 7일 평균, 신체 프로필, BMI 눈금, 대사량·소비열량·목표 적용, 생활 기록·습관 체크와 기록 이력.
- [ ] app-motion.js / motion.css: 페이지·카드·모달·리스트·숫자·체중 선·막대·프로그레스·버튼·습관 체크 애니메이션. 반복 렌더 시 값은 이전 값에서 이어지고 포커스는 유지한다. OS 동작 줄이기 및 앱 설정으로 즉시 비활성화한다.
- [ ] 브라우저: 새 기록·편집·삭제·목표 적용·지난 날짜·기존 백업·새 백업·모션 설정·단축키·반응형 검증. 독립 코드 검토 후 같은 GitHub Pages 주소로 게시하고 실제 링크 확인.

입력 범위: 신장 80–250cm, 연령 19–100세, 체중 20–500kg, 체지방률 1–75%, 허리둘레 30–250cm, 수면 0–24시간, 운동 0–1440분, 걸음 수 0–100000. 하루 체중은 하나이며 같은 날짜 입력은 갱신한다. 프로필 전에도 체중·생활 기록은 가능하다. 체중 그래프는 실제 날짜 간격을 사용하고 미래 기록을 현재 수치로 사용하지 않는다.

기초대사량 카드에는 정확히는 휴식대사량 공식을 이용한 추정임을 표시한다. 성인 참고용이며 개인별 실제 대사량은 다를 수 있다. 활동 기록의 운동을 소비열량에 중복 가산하지 않는다. 감량 예시는 현재/목표가 저체중 범위거나 남 1500/여 1200 kcal보다 낮아지면 제시하지 않는다. 이러한 하한은 개인별 안전 섭취량을 보장하는 값이 아닌 앱의 자동 예시 제한이다. 유지가 기본 선택이다. 감량 날짜·속도를 보장하지 않는다.

근거: Mifflin et al. 1990, PMID 2305711; 대한비만학회 성인 BMI 구간; NIH/NHLBI 체중 관리 자료; CDC 성인 신체활동 가이드. 화면의 계산 안내에 원문 링크와 앱이 선택한 활동계수·10% 조정 가정을 구분해 적는다.
