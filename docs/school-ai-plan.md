# 학교 점심·AI 코치·한 화면 구성

2026-11-13 사용자 요청: 평일 학교 점심 950kcal, 공휴일 제외; Gemini 4 Hydrogen으로 기록 분석·추천; 긴 페이지와 의도하지 않은 확대·선택 줄이기.

1. 학교 점심은 2026-11-13부터 오늘까지의 평일에 가상 기록으로 한 번만 합산한다. 2026·2027 대한민국 공휴일·대체공휴일을 제외한다. 당일 제외·방학/휴업 기간·자동 반영 중지와 열량 변경을 지원한다. 기존 수동 식단을 덮어쓰지 않는다. 사용자가 지정하지 않은 탄단지·실제 중량은 만들지 않는다. 자동 점심은 앱 합계·주간 보고서·AI 도구에서 동일하게 계산한다.
2. AI는 고정 `gemini-4-hydrogen`을 사용하며 유료 모델로 자동 전환하지 않는다. 키는 소스·Git·백업·URL에 넣지 않는다. 연결한 탭의 sessionStorage에만 보관하고 삭제 기능을 제공한다. 실제 기록 요약을 읽는 도구를 호출하는 읽기 전용 에이전트로 구성한다. 분석 버튼에서 Google 전송을 설명한다. 요청 취소·시간 초과·인증·할당량 오류를 숨기지 않는다. 모델 출력은 HTML로 실행하지 않는다.
3. 몸 관리는 요약/체중/BMI/대사량/생활/습관/기록 세부 탭으로, 리포트는 차트/영양/기록 탭으로 나눈다. 기본 화면은 뷰포트 안에 배치하고 긴 목록만 내부 스크롤한다. 작은 높이·큰 글꼴·브라우저 확대에서도 기능이 잘리지 않도록 내부 스크롤 대안을 둔다. 입력 글꼴은 최소 16px, 컨트롤은 의도하지 않은 이중 탭 확대와 텍스트 선택을 줄인다. 본문 선택과 사용자가 의도한 브라우저 확대는 유지한다.
4. 단위·주말·공휴일·날짜 범위·중복·설정/백업, AI 요청·도구·응답·오류·취소를 테스트하고 실제 브라우저에서 사용자 기록을 보존하여 검증한다. 독립 코드 검토 후 기존 GitHub Pages에 게시하고 제공된 키로 사용자 탭의 연결을 완료한다.

근거: Google 공식 모델 목록·가격표, 우주항공청 2027 월력요항 발표 및 한국천문연구원 2026·2027 달력자료. 무료 티어는 계정별 할당량 제한이 있고 요금제 설정에 따라 과금 정책이 다를 수 있으므로 ‘무조건 무제한 무료’라고 표시하지 않는다. 공휴일 반영 범위 외 연도에는 확인 없이 자동 점심을 추가하지 않는다.
