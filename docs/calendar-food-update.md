# 달력·음식 분류 업데이트 — 2026-11-15

사용자 요청: AI 코치 제거, 중복 음식 정리, 칼로리 초과·적자 달력, 직접 해먹기/완제품 분리.

달력은 설정한 섭취 목표 대비 기록 합계의 차이로 계산하며 실제 에너지 소비량과의 차이라고 표현하지 않는다. 미기록·미래는 적자로 취급하지 않는다. 학교 점심은 공휴일/주말 제외와839/107/36/30추정 평균을 유지한다. 목표 변경은 오늘부터 적용하며 날짜별 목표 이력을 백업한다. 백업 복원은 기존 이력을 그대로 보존한다.

음식은 종류·정규화 이름·완제품 제조사별로 한 항목에 묶는다. 동일 영양소·단위·1인분 기준량의 중복은 제거하고 다른 기준은 상세 선택으로 유지한다. 검색 worker가 그룹을 먼저 만든 뒤 상위100종을 보내므로 같은 이름의 여러 기준이 검색 자리를 차지하지 않는다. 기존 식단 기록을 지우거나 합치지 않는다. 사용자 음식의 종류는 저장과 백업에 포함한다.

AI UI/코드/연결 저장 기능을 제거하고 이전 키를 앱 시작 시 정리한다. 식단·체중 데이터와 백업 호환은 유지한다. 기존#agent링크는 달력으로 연결한다. 기능 테스트, 실제 데스크톱/모바일 브라우저, 독립 검토 후 기존 GitHub Pages에 게시한다.
