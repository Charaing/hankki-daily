# 한끼 검증 기록

검증일: 2026-11-12 (Asia/Seoul)

## 기능 검증

- Node 테스트 7개 통과: 그램·소수 인분 계산, 단위 변환 정밀도, 0·음수·비정상 수량 거부, mL 단위 유지, 누락 영양소, 날짜 이동, 백업 검증.
- 실제 Chrome에서 음식 검색 → 210g 쌀밥 348.6kcal → 인분 전환 → 저장 → 새로고침 후 유지 → 수정 → 삭제 → 삭제 취소를 확인.
- 날짜 이동, 물 250mL, 목표 수정, 직접 등록, 문자 이스케이프, 즐겨찾기, 보관함, 리포트, 백업 다운로드와 복원 확인.
- 잘못된 백업과 HTML을 삽입하려는 기준량 입력을 거부함을 확인.
- 실제 국내 검색 목록 352,361건 로딩, 모든 데이터 행의 영양정보 스키마 검증 통과.
- 모바일 음식 선택 시 상세 제목에 키보드 포커스가 이동하며 목록 복귀가 가능함을 확인.
- 1440 / 1024 / 768 / 390 / 320px에서 수평 넘침 없음. 모바일 하단 메뉴와 전용 상세 화면 확인.
- 브라우저 실행 중 JavaScript 예외 없음.

## 코드 검토

독립 검토에서 발견한 세 문제를 수정했습니다.

1. g↔인분 전환 시 두 자리 반올림으로 실제 먹은 양이 달라지던 문제: 계산 정밀도를 유지하고 표시만 반올림.
2. 같은 이름·칼로리·제조사이지만 탄단지 또는 기준량이 다른 식품이 검색 중복 처리되던 문제: 모든 영양소·기준량·출처를 포함하여 판정.
3. 백업 복원 시 무게 모드의 `servingSize` 검증 누락: 모든 모드에서 유한한 양수인지 검증하고 비정상 백업을 거부.

추가로 물 250mL가 0.3L로 표시되던 문제, 보이지 않는 보관함 날짜 도구의 표시, 원형 그래프 안 아이콘 회전, 날짜 선택의 키보드 접근과 흐린 보조 텍스트를 수정했습니다.

## 디자인 도구 결과

`GATE: OPEN 40 (rounds used up)`

이 도구는 회사 소개·랜딩 페이지를 전제로 전체 화면 히어로, 한 화면에 섹션 하나, 상단 가로 내비게이션, 큰 사진·효과와 장면 전환을 요구합니다. 이 프로젝트는 사용자가 요청한 실제 식단 기록 앱이므로 사이드바·정보 카드·큰 섭취 숫자·모달·하단 앱 메뉴를 유지했습니다. 이 자동 디자인 게이트를 통과했다고 주장하지 않습니다. 남은 항목의 정확한 전체 출력은 [design-gate.txt](design-gate.txt)에 있습니다. 별도의 도구 면제(waiver)는 등록하지 않았습니다.

실제 사용에 영향을 주는 대비와 모바일 탭 대상은 개선했고, 기능 테스트와 5개 화면 너비에서 별도로 확인했습니다. 디자인은 흰 카드, 연한 회색 배경, 파란 포인트, Pretendard와 동일한 라운드·간격 체계를 사용합니다. 사진 대체물, 고객 실적, 연락처, 예약 폼, 외부 자산을 가장한 자료는 없습니다. 이름 ‘한끼’는 일상어로 택한 독립 앱 이름이며 상표 독점성을 주장하지 않습니다.

## 외부 연결과 한계

- Open Food Facts 추가 검색은 실제 요청 시 외부 서버가 503을 반환하여 성공 결과를 검증하지 못했습니다. 실패를 숨기지 않고 사용자에게 안내하며 별도 검색 사이트 링크와 직접 등록 경로를 제공합니다. 국내 352,361건의 앱 내부 검색은 영향을 받지 않습니다.
- 실제 iOS Safari·Android 기기에서의 실행은 확인하지 못했습니다. 데스크톱 Chrome의 모바일 화면과 터치 크기에서 검증했습니다.
- 계정 간 동기화와 서버 저장은 없으며, 공개 목록은 자동 갱신되는 실시간 자료가 아닌 저장소에 포함한 버전입니다.
- 원본 수록 음식 전체를 보장하지 않습니다. 빈 영양값은 ‘정보 없음’으로 유지합니다.
